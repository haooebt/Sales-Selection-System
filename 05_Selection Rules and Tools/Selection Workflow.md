# 选型工作流

## 入口 1：客户有竞品

```text
竞品型号/规格书
-> 判断竞品类别
-> 读取 Product Quick Locator
-> 提取关键参数
-> 判断封装和 pinout
-> 判断资源和外设
-> 查我司产品参数矩阵
-> 形成候选型号
-> 标注差异和风险
-> 输出替代建议
-> 沉淀到竞品替代表
```

输出必须包含：

- 竞品类别
- 主推型号
- 备选型号
- 替代等级
- 不匹配项
- PCB/软件迁移风险
- 待确认问题

## 入口 2：客户有参数需求

```text
客户参数需求
-> 区分硬性需求和弹性需求
-> 建立最低配置
-> 筛选我司产品矩阵
-> 按成本/余量/开发难度排序
-> 输出主推和备选
-> 记录风险和待确认项
```

输出建议：

- 主推型号：最平衡
- 备选型号：成本优先
- 备选型号：资源余量更大
- 不推荐型号：说明原因

## 入口 3：客户只有项目场景

```text
终端项目/行业场景
-> 查应用方案卡
-> 推导关键需求
-> 列出待确认问题
-> 给出初步方案和型号建议
-> 客户确认参数后进入参数选型流程
```

输出重点：

- 初步方案方向
- 推荐产品组合
- 需要客户补充的信息
- 可参考的历史案例
