衣物分布不均匀的情况下，会导致滚筒偏心、重量不平衡,因此在滚筒洗衣机脱水前需要进行不平衡检测，作为是否进入脱水流程的判断依据。

桶速运行到某指定速度时，衣物受离心的作用，紧贴滚筒的内侧,滚筒内的不平衡会引起电机的转矩脉动，因此可以利用该转速下的转矩脉动进行负载不平衡估计。

PMSM输出的机械功率为： $T _ { e } = \cfrac { P } { \Omega } = \cfrac { P } { ( \cfrac { \omega _ { m } * 2 \pi } { 6 0 } ) } = 9 . 5 5 * \cfrac { P } { \omega _ { m } }$

为转子的角速度(单位：rad/s)，P为电机功率

$\omega _ { m }$ 为转子的机械转速(单位：rpm)

◆ 电机稳定运行时，功率基本恒定，转矩脉动可以通过转速波动进行检测。

转速/矩波动表征不平衡程度的大小，软件通过特定算法进行不平衡数据的区分，达到测量数据的可重复性、可区分性、一致性。

◆ 称重实质上是辨识滚筒的转动惯量

◆ 利用加速段的功率大小，计算转动惯量。

◆ 具体过程：电机在稳定转速n0时，记录当前的输入功率值(基准功率)P0，将滚筒加速到n1,记录当前的输入功率值P1，P1-P0得到加速过程的功率，从而可以计算出滚筒的转动惯量。

$$
\mathsf {E n e r g y} = \frac {1}{2} J w 1 ^ {2} - \frac {1}{2} J w 2 ^ {2}
$$

◆ 不同机型通过标准偏心块进行标定。
