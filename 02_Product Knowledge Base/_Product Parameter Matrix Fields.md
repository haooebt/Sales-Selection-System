# 产品参数矩阵字段建议

建议产品参数矩阵至少包含以下字段：

| 字段 | 说明 |
|---|---|
| Product Line | 产品线 |
| Series | 系列 |
| Device | 型号 |
| Positioning | 一句话定位 |
| Core | 内核 |
| Freq MHz | 主频 |
| Flash KB | Flash |
| RAM KB | RAM |
| ADC | ADC 数量/精度 |
| ADC Channels | ADC 通道 |
| DAC | DAC |
| COMP | 比较器 |
| OPA | 运放 |
| Timer/PWM | 定时器/PWM |
| CAN | CAN/FDCAN |
| UART | UART/USART |
| SPI | SPI |
| I2C/IIC | I2C |
| USB | USB |
| Motor Features | 电机控制特性 |
| Gate Driver | 是否内置 gate driver |
| Supply | 供电范围 |
| Temperature | 温度等级 |
| Package | 封装 |
| Pin Count | 脚数 |
| Key Strength | 核心优势 |
| Known Limits | 已知限制 |
| Suitable Applications | 适合场景 |
| Unsuitable Applications | 不适合场景 |
| Source | 资料来源 |
