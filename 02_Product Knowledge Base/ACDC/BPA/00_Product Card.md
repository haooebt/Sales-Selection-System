# ACDC BPA 系列产品卡

资料来源：03_Parsed_Markdown/ 解析结果 + 原始PDF

## 1. 一句话定位

BPA系列是晶丰明源的高端ACDC电源驱动芯片产品线，以700V-825V高压MOSFET集成、超低待机功耗为特色，
覆盖Buck/Buck-Boost/Flyback多种拓扑，主要面向家电辅助电源、工业控制等可靠性要求较高的应用。

## 3. 共同特性

- **全系集成高压启动和自供电电路**，无需外部启动电阻
- **低待机功耗**: <50mW(辅助绕组供电)，<150mW(高压自供电)
- **保护功能**: 输出短路(SCP)、过压(OVP)、过载(OLP)、逐周期限流、过温(OTP)
- **多模式控制**: PWM/PFM自适应，轻载效率优化

## 4. 功率梯度（反激系列）

```
BPA8618D  (16W/10W)  →  700V
BPA8618PD (24W/18W)  →  750V
BPA8619P  (28W/22W)  →  750V
BPA8620PD (32W/25W)  →  750V
BPA86525PC(32W/21W)  →  825V (最高耐压)
BPA86528D (65W/52W)  →  800V, SOP-10 (最大功率)
```

## 5. 选型方向

| 场景 | 推荐 | 理由 |
|---|---|---|
| 家电辅助电源 <10W | BPA8504D/05D | SOP-7小封装，Buck拓扑 |
| 家电辅助电源 10-16W | BPA8618D | 700V反激成熟方案 |
| 白电高压场景 18-24W | BPA8618PD/BPA8619P | 750V耐压更安全 |
| 三相工业电源 25-32W | BPA8620PD | 大功率反激 |
| 高可靠性要求(电网不稳) | BPA86525PC | 825V+6kV ESD |
| 大功率家电 50W+ | BPA86528D | SOP-10封装，65W输出 |

## 6. 注意

- BPA8618G/BPA8618PD管脚定义与BPA8618P相同（DIP-7封装，Pin-to-Pin兼容）
- BPA86525PC/526PC/528D 系列使用不同封装，不兼容
- 反激系列ESD统一为2kV，BPA865xx系列升级到6kV
