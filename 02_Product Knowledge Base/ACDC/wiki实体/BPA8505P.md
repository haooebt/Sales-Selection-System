# BPA8505P — DIP-7 封装中功率高压非隔离/隔离开关电源驱动芯片

## 概述

BPA8505P 是 [[wiki/实体/BPA8505D]] 的 **DIP-7 封装版**——同 Die、同电气参数，但封装从 SOP-7 变为 DIP-7，带来显著的热性能提升。

| 参数 | BPA8505D (SOP-7) | **BPA8505P (DIP-7)** | 优势 |
|------|:-:|:-:|------|
| 封装 | SOP-7 | **DIP-7** | 插件式，更易手工焊接 |
| Pdmax | 0.97W | **1.5W** | +55% 功耗耐受 |
| θJA | 129°C/W | **80°C/W** | 散热优 **1.6×** |
| θJC | 70°C/W | **20°C/W** | 结到壳热阻优 **3.5×** |
| ESD | 2kV | 2kV | 相同 |
| 所有电气参数 | — | — | **完全相同** |

> **核心定位**：BPA8505P 是高温/大功率场景下 BPA8505D 的直接替代方案。同样的 Die 在 DIP-7 封装中能承受更高环境温度或输出更大功率。适合家电内部高温环境（如电磁炉、电饭煲、空调内机）。

## 完全共享的参数（与 BPA8505D 100% 相同）

- VCC_ON=6.4V, VCC_HYS=1.4V, VCC_CLAMP=7V
- VFB_REF=1.7V, VFB_OVP=2.9V/4cyc, VFB_OLP=1.1V/400ms, VFB_SC=0.4V/2048cyc
- fS_MIN=1kHz, fS_MAX=45kHz, DMAX=60%, tLEB=260ns
- ILIMIT_MAX=440mA (404~476mA), ILIMIT_MIN=0.2×≈88mA
- Rds(on)=8.5Ω typ/10Ω max, BVdss=700V
- TOTP=145°C, THYST=40°C
- 软启动 40%/63Ts→70%/64Ts→100%
- 控制模式：PWM/PFM 多模式
- Buck/Buck-Boost/Flyback 电感公式、假负载公式、纹波公式完全相同

详见 [[wiki/实体/BPA8505D]] 获取完整电气参数表和设计指南。

## 管脚说明 (DIP-7)

DIP-7 引脚排列与 SOP-7 不同：

| 管脚 | 名称 | 功能 |
|------|------|------|
| 1, 7, 8 | GND | 芯片地，内部 MOSFET 源极（三脚并联增强散热） |
| 2 | NC | 无连接 |
| 3 | VCC | 芯片电源，需外接 0.1μF 旁路电容到 GND |
| 4 | FB | 输出电压反馈，通过分压电阻采样实现输出电压调节 |
| 5 | DRAIN | 内部 MOSFET 漏极，同时向芯片提供自供电电流 |

> DIP-7 的三个 GND 引脚（1/7/8）并联设计带来更低的封装引线电阻和更好的散热路径，这是 θJA 从 129→80°C/W 的关键因素之一。

## ⚔️ 两份竞品对比 VS LNK305P

### 1. 15V/250mA 对比 (陈耀兵, 2021/3)

| | BPA8505P | LNK305P |
|---|:-:|:-:|
| 待机@230V | **127mW** | 134mW |
| 满载效率@115V | **79.2%** | 77.1% |
| 满载效率@230V | **76.6%** | 75.1% |
| 满载纹波@85V | 33.6mV | **33mV** |
| 满载纹波@265V | 41.5mV | **39mV** |
| 50%-100%动态@265V | 146mV | **99mV** |
| 10%-90%动态@265V | 272mV | **205mV** |
| **温升@265V 50°C** | **81.6°C** | **104.1°C** ⚠️ |
| IDS_MAX@265V | **0.764A** | 0.858A |
| 负载调整率 | **2.32~2.40%** | 7.65~7.90% |

> **温升碾压**：BPA8505P 比 LNK305P 低 **22.5°C**！DIP-7 的 80°C/W θJA vs LNK305P 同封装但不同控制架构的劣势。LNK305P 在 50°C 环温下达 104°C，距 OTP 仅 41°C。

### 2. 14V/200mA 对比 (文长川, 2021/10) — 含二极管优化实验

| | BPA8505P | LNK305P |
|---|:-:|:-:|
| 满载效率@115V | **75.8%** | 70.0% |
| 满载纹波@265V | **89.3mV** | 124mV |
| 50%-100%动态@265V | **391mV** | 679mV |
| **温升@265V** | **Δ26.2°C** | Δ38.5°C |
| 负载调整率 | **2.74~3.12%** | 5.85~6.60% |

#### 🔬 二极管优化关键实验

| | US1M (改前) | **ES1J (改后)** |
|---|:-:|:-:|
| 50%-100% 动态 | 807mV | **391mV (-52%)** |
| 10%-90% 动态 | 1200mV | **776mV (-35%)** |
| 负载调整率 | 3.12% | **0.58% (-81%)!** |
| 短路 IDS_MAX | 1.2A | **0.95A (-21%)** |
| 开机过冲 | 有 | **无** |

> **结论**：D17/D18 续流/反馈二极管从 US1M 更换为 ES1J (trr≤35ns) 后，动态响应改善 52%，负载调整率从 3.12% 骤降至 0.58%，改善幅度达 81%。**反向恢复时间 trr 是决定 BPA8505P 性能的关键外围元件参数**。

### 双路输出交叉调整率

BPA8505P 的两份双路参考设计均使用抽头电感（Tapped Inductor）方案，而非 Flyback 变压器：

| 双路设计 | 主路满载/辅路空载 | 辅路电压飘移 |
|----------|-------------------|-------------|
| 5V+12V | 5V/200mA满载, 12V空载 | 12V→**12.87V** (+7.3%) |
| 12V+15V | 12V/500mA满载, 15V空载 | 15V→**15.30V** (+2.0%) |

> 抽头电感的交叉调整率远优于 PSR Flyback 双路方案（后者通常飘移 20%+），但仍有不可忽视的电压偏差。12V+15V 设计因两路电压接近+15V 仅 50mA 轻载，交叉调整率明显优于 5V+12V 方案。

## 与 BPA8505D 的选型建议

| 场景 | 推荐芯片 | 原因 |
|------|----------|------|
| 环境温度 >60°C 封闭空间 | **BPA8505P** | θJA=80 vs 129°C/W，高温裕量充裕 |
| 输出功率 >5W | **BPA8505P** | Pdmax=1.5W vs 0.97W |
| 空间受限 SMD 产线 | BPA8505D | SOP-7 贴片封装 |
| 成本敏感批量生产 | BPA8505D | SOP-7 成本更低 |
| 需要手工焊接/原型验证 | **BPA8505P** | DIP-7 插件式 |
| BPA8505D 热测试不通过 | **BPA8505P** | 直接替换（仅PCB改封装） |

> **引脚不兼容注意**：DIP-7 和 SOP-7 的引脚排列不同，不可直接互换 PCB Layout。DIP-7 有 NC(2脚) 和三 GND(1/7/8脚)，SOP-7 是 VCC(1脚) FB(2脚) DRAIN(4脚) GND(5/6/7/8脚)。
