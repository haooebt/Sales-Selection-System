# BPA86526PC — 800V/3.0Ω PFM/PWM Flyback 中档型号 (DIP-7)

## 📋 芯片概述

BPA86526PC 是 BPA865xx 系列的中档型号，800V/3.0Ω MOSFET，功率 18-32W。定位介于 BPA86525PC (825V/3.9Ω) 和 BPA86526P (800V/2.1Ω) 之间。2026/01 与 BPA86525PC 同期首发。

## ⚡ 与 BPA86526P 关键差异

| 参数 | BPA86526PC | BPA86526P |
|------|-----------|-----------|
| Rds(on) | 3.0Ω | **2.1Ω** |
| IS2 | 2.22mA | 3.8mA |
| DMAX | 78% | 75% |
| I_D/I_DM | 3.5A/10A | 4A/16A |
| ESD | 5kV | 6kV |
| 功率 | 18-32W | 20-36W |
| DS 日期 | 2026/01 | 2024/11 |

## ⚡ 核心电气参数

| 参数 | 值 |
|------|-----|
| BVdss | 800V |
| Rds(on) | 3.0Ω typ / 3.5Ω max |
| VCS_LIMIT | 0.97V (0.88~1.2V) |
| fsw | 100kHz+16kHz 抖频 |
| DMAX | 78% |
| tLEB | 400ns |
| VCC ON/OFF/OVP | 15V/8V/38.5V |
