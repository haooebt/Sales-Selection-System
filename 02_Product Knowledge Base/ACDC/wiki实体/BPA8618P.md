# BPA8618P — BPA8616P 功率升级版 隔离反激芯片 (DIP-7)

## 📋 芯片概述

BPA8618P 是 BPA8616P 的**功率升级版**，同样采用脉冲数控制架构（132kHz, 频率调制），但内置 MOSFET 参数全面升级：Rds(on) 从 11Ω 降至 **4.5Ω** (-59%), ILIMIT 从 350mA 提升至 **550mA** (+57%), IDS_MAX 从 910mA 提升至 **1290mA**。输出功率从 BPA8616P 的 7-12W 跃升至 **10-24W** (全电压/230V)。

## ⚡ 与 BPA8616P 差异矩阵

| 参数 | BPA8618P | BPA8616P | 差异 |
|------|----------|----------|------|
| Rds(on) | **4.5Ω** (max 5.2) | 11Ω (max 14) | **-59%** |
| ILIMIT_MAX | **550mA** (510-590) | 350mA (326-374) | **+57%** |
| ILIMIT_MIN | **220mA** | 140mA | +57% |
| IDS_MAX | **1290mA** (2430@<400V) | 910mA (1710@<400V) | +42% |
| ICC (max) | 515μA | 350μA | +47% |
| ICH1 (VCC=0V) | -6.3mA | -6.9mA | 略低 |
| ISD (OVP) | 6.9mA | 7.2mA | 略低 |
| 适配器 85~265V | **10W** | 7W | +43% |
| 开放 85~265V | **18W** | 12W | +50% |
| 适配器 230V | **16W** | 10W | +60% |
| 开放 230V | **24W** | 15W | +60% |
| ESD DRAIN | 1.5kV | 2kV | 略低 |
| DS 日期 | 2022/4 | 2021/6 | 更新 |

> 其他所有参数完全一致：VCC_ON=5.8V, fosc=132kHz, DMAX=65%, tLEB=300ns, VIN_BR=85V, VDRAIN_OV=600V, TOTP=145°C, 故障保护时序, Flyback 设计方法论等。

## 🔧 工程注意要点

1. **Rds(on)=4.5Ω 是 BPS 脉冲数控制系列最低内阻**（仅次于 BP86213D 的 3.8Ω PSR 芯片），使 24W 开放式输出成为可能
2. **16V/1.4A 非隔离方案效率 >85%@230V** 为全库 BPS Flyback 效率最高记录——得益于低 Rds(on)+高输出电压组合
3. **12V/850mA 极简 25BOM** 方案在 265VAC 满载时 IC 温度达 122°C——距 OTP 仅 23°C, 需严格热管理
4. **前馈电容的影响**：12V/850mA 方案中, 有前馈电容 IC 温度 122°C vs 无前馈 111°C@265V/0.7A——前馈电容会增加 IC 开关损耗
5. **多路输出交叉调整**与 BPA8616P 系列类似——5V+12V 双路 12V 空载飘至 17.7V
6. **DS Rev.1.0 (2022/4)** 比 BPA8616P DS (2021/6) 晚 10 个月——BPA8618P 是 BPA8616P 产品成熟后的扩功率迭代
