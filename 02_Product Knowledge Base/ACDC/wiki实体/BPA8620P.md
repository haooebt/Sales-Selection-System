# BPA8620P — 700V 超低内阻 Flyback 脉冲数控制芯片 (DIP-7)

## 📋 芯片概述

BPA8620P 是晶丰明源 BPA86xx 大电流 Flyback 系列的主力型号，集成 700V 高压 MOSFET (Rds(on)=**2.4Ω typ，脉冲数控制架构中最低**)，采用脉冲数控制架构（132kHz + 8kHz 频率调制），无需外部环路补偿。DIP-7 封装，θJA=80°C/W，内置软启动和输入 OVP/UV 保护（免外置采样电阻），特别适合于隔离反激辅助电源应用。

## ⚡ 核心电气参数

| 参数 | 值 |
|------|-----|
| BVdss | **700V** |
| Rds(on) | **2.4Ω** typ / 2.8Ω max |
| ILIMIT_MAX | **750mA** (695~805mA) |
| ILIMIT_MIN | 0.4×ILIMIT_MAX = ~300mA |
| IDS_MAX | 1410mA (2650mA@VDS<400V) |
| fsw | 132kHz typ (124~140kHz), 8kHz 调制 |
| DMAX | 65% |
| tLEB | 300ns |
| tOFF_Delay | 100ns |

## 🛡️ 保护功能

| 保护 | 机制 | 关键参数 |
|------|------|----------|
| 输入 OVP | DRAIN 检测，关断 MOSFET | V_DRAIN_OV=600V typ (570~630), 迟滞 150V |
| 输入 UV (Brown-in) | DRAIN 检测，禁止启动 | V_IN_BR=85V (77~93V), 持续 30μs |
| 输出 OVP | VCC 引脚电流检测 | Isd=7.5mA, 自动重启 t_AR_OFF=1.8s |
| SCP | FB 电流持续 <IFB_DIS 61.4ms | t_AR_OFF1=1.8s 自动重启 |
| OLP | FB 电流持续 <IFB_DIS 45ms (正常工作) | t_AR_OFF2=200ms 自动重启 |
| 逐周期限流 | 内部电流采样 | ILIMIT_MAX=750mA |
| OTP | 芯片结温检测 | 145°C 触发, 70°C 迟滞 |
| 反馈开路 | FB 脚开路检测 | 同 SCP 逻辑 |

## 🔧 参考设计

### 12V/1.5A 基础方案 (DS 内置)
- 变压器: EE25, Flyback 隔离
- 输出二极管: 肖特基, VF 小
- 输出电容: 2×电解并联
- 控制: 光耦 PC817 + TL431
- PCB: 单面板

### [[wiki/来源/2022-10_BPA8620P_洗碗机电源参考设计_BPS | 洗碗机三路输出方案]]
- 5V/1A + 12V/1A + 18V/0.23A (21.14W)
- 输入 176-264VAC
- EE25, Lp=850μH
- 满载效率 ~77.5%, 纹波 5V:75mV/12V:157mV/18V:113mV
- ⚠️ 三路交叉调整率: 12V 空载时飙升到 14.5V
