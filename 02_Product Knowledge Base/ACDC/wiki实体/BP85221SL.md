# BP85221SL — 全库最小：SSOP-6 / 30mA / 6元件BOM / 替换阻容降压

**SSOP-6 极小封装 | 800V整流+550V/25Ω全集成 | 5V/30mA | 6元件BOM(全库最少!) | 兼容CD43贴片电感**

BP85221SL 是 BPS 产品线中**封装最小、BOM最少、功率最低**的芯片，专为替换传统阻容降压方案而设计。频率自适应控制(非PWM/PFM)、77kHz高频、CD43贴片电感兼容——这三项特性使其在小家电/IoT的超低功耗辅助电源场景中占据极致性价比。

## 🔬 关键功能机制

### 频率自适应控制 — 与 BP852xx 体系的根本差异

BP85221SL/AL 使用**频率自适应控制**，而非 BP852xx 系列的 PWM/PFM 多模式控制：

```
BP852xx 体系: PWM/PFM 多模式
  • 重载: 混合模式 (ILIMIT↑ + fsw↑)
  • 中载: PWM (fsw固定 + ILIMIT↓)
  • 轻载: PFM (ILIMIT固定 + fsw↓)

BP85221SL/AL: 频率自适应
  • 控制维度单一: 仅调频率, ILIMIT固定
  • fsw 随负载连续变化: 2.8k~77kHz
  • 没有离散的 PWM/PFM 模式切换
  • 软启动: 频率随 VOUT 逐渐升高(非ILIMIT阶梯!)
```

频率自适应控制更简单、更省晶圆面积——这正是 SSOP-6 超小封装能实现全集成的前提。

### 1.8μs tON_MAX — 全库最短

BP85221SL 的 tON_MAX=1.8μs 是全库最短（vs BP85224A 的 7μs / BP85224DA 的 8μs）。在 5V/77kHz Buck 中：
- T=13μs, D=5/373=1.34%, tON≈0.17μs
- 1.8μs 的 tON_MAX 对此绰绰有余
- 短 tON 限制了最大占空比 → 这解释了为什么 21SL 仅支持 30mA 输出即可——不需要大占空比的 CCM 重载

### 保护体系简化

与 BP852xx 系列(OVP+SCP+OLP+OTP)不同，BP85221SL 仅提供：
- **OLP**(VO<3.3V/1024cyc): 同时覆盖输出过载和短路
- **OTP**(145°C/40°C): 过温保护
- **逐周期限流**(tLEB=200ns): 防止 MOSFET 过流

无独立 OVP 和 SCP——这是超低功耗芯片的成本/面积优化选择。

### 兼容贴片电感 — 全库独特

BP85221SL/AL 可以兼容 **0510色环电感** 或 **CD43贴片电感**(1mH/1.5mH)。CD43 贴片电感是全自动 SMT 产线的理想选择——传统工字电感需要手工插件，CD43 可完全自动化。这是 BPS 针对大规模消费电子产线的重要产品定义。
