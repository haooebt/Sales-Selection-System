# BP85956D — 12V/300mA 免VCC电容非隔离Buck/Buck-Boost驱动芯片

## 概述

BP85956D是晶丰明源高性能、高集成度、低待机功耗的开关电源驱动芯片，适用于全电压85~265VAC输入的Buck、Buck-Boost变换器拓扑应用。内部集成650V高压MOSFET、高压启动和自供电电路、电流采样电路、输出电压采样电阻，采用先进的多模式控制技术（PWM/PFM），无需外部VCC电容和环路补偿即可实现优异的恒压输出特性。

核心差异定位：与姊妹芯片 BP85956P（DIP-7）共享同一Die，SOP-8封装更适合空间受限场景，但热阻较高（129°C/W vs 80°C/W）。

## 多模式控制架构

BP85956D采用PWM/PFM多模式控制，与BP852xx家族架构一致：

- **重载PFM**：限流点保持ILIMIT_MAX(600mA)，频率随负载从22kHz升至45kHz
- **中载PWM**：频率固定22kHz，限流点从600mA降至180mA
- **轻载PFM**：限流点保持ILIMIT_MIN(180mA)，频率从22kHz降至0.5kHz
- **空载**：最低频率0.5kHz，最低限流180mA，有效抑制音频噪声

## 软启动

三级限流点渐进式软启动：

1. 起始限流 = 50% ILIMIT_MAX (300mA) → 持续32个开关周期
2. 升至75% ILIMIT_MAX (450mA) → 持续32个开关周期
3. 结束软启动，限流恢复100% (600mA)

总计64开关周期完成软启动。保护触发的重启同样经历此软启动过程。

## 输出电压采样

通过FB引脚采样输出电压。反馈二极管在MOSFET关断时导通，将输出电压信息反馈至FB引脚。输出电压采样仅在续流状态3μs时进行，因此**电感设计必须保证续流时间>7μs**以防止采样异常。

约束条件：L ≥ (VOUT × 7μs) / ILIMIT_MIN

## 应用指南核心公式

### Buck拓扑电感计算

**CCM模式** (IOUT > 0.5×ILIMIT_MAX):

L_MIN = (VOUT+VDiode)×(VIN-VDS-VOUT) / [(VIN-VDS+VDiode)×fS×ΔIL]

其中 ΔIL = 2×(ILIMIT_MAX - IOUT), VDS = IOUT×Rds(on)

**DCM模式** (IOUT < 0.5×ILIMIT_MAX):

L_MIN = 2×IOUT×(VOUT+VDiode)×(VIN-VDS-VOUT) / [(VIN-VDS+VDiode)×fS×ILIMIT_MAX²]

其中 VDS = 0.5×ILIMIT_MAX×Rds(on)

**空载约束**（防失控）:

L ≥ tLEB×(VIN_MAX-VOUT) / ILIMIT_MIN

### Buck-Boost拓扑电感计算

**CCM模式**：使用修正电压VIN'=VIN-VDS, VOUT'=VOUT+VDiode

L_MIN = 0.5×VOUT'×VIN'²×(1/fS) / [(VIN'+VOUT')×(VIN'×ILIMIT_MAX-(VIN'+VOUT')×IOUT)]

**DCM模式**:

L_MIN = 2×(VOUT+VDiode)×IOUT / (ILIMIT_MAX²×fS)

**Buck-Boost纹波**：ΔVESR = ILIMIT_MAX×ESR（适用DCM/CCM，纹波电流比Buck大）

### 假负载计算

IAVG = 0.5×IL×(TON+TOFF)×fS_MIN

IL = (VIN_MAX/L)×tDelay + ILIMIT_MIN

实际需额外1~3mA裕量（芯片自供电电流）。

### 续流/反馈二极管选型

- 续流二极管：trr≤35ns超快恢复，600V+耐压，额定电流=3~4×IOUT，推荐ES1J
- 反馈二极管：600V+超快恢复，推荐ES1J

### 输入电容

- 全波整流：≥3μF/W
- 半波整流：≥6μF/W
- 单高压176~265VAC：容量可减半

### 输出电容

- DCM纹波由ESR主导：ΔVESR = ILIMIT_MAX×ESR
- CCM纹波：ΔVESR = ΔIL×ESR

## PCB Layout关键指南

1. FB避免铺铜，远离高压/电压动点
2. GND铺铜散热但面积尽量小（电压动点），远离交流输入端
3. SW接直流母线(电压静点)，可铺铜散热，与FB/GND走线距>2mm
4. 尽量缩小功率环路（励磁+续流回路）面积
5. 功率回路走线宽而短
