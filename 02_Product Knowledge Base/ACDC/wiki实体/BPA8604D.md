# BPA8604D — 700V SOP-7 隔离 Flyback + 脉冲数控制芯片

## ⚠️ 重要更正

本实体页根据 DS Rev.1.3 (2025/10) 全面重写。旧版基于参考设计存在多处错误：
- ~~SOP-8~~ → **SOP-7**
- ~~抽头电感 Buck~~ → **隔离 Flyback**（DS 明确"隔离反激辅助电源应用"）
- ~~Rds(on)/ILIMIT 未披露~~ → **20Ω / 250mA**

## 概述

BPA8604D 是 [[wiki/实体/BPA8604P]] 的 **SOP-7 封装版**——同 Die（700V/20Ω/250mA/132kHz 脉冲数控制），无 ZCD 功能。SOP-7 封装 θJA=129°C/W（vs DIP-7 的 80°C/W）。

| 参数 | BPA8604D (SOP-7) | BPA8604P (DIP-7) |
|------|:-:|:-:|
| 封装 | SOP-7 | DIP-7 |
| θJA | **129°C/W** | 80°C/W |
| Pdmax | 1.5W | 1.5W |
| ZCD | ❌ 无 | ✅ VAC+ZC 引脚 |
| 引脚数 | 7 (VCC/FB/DRAIN/4×GND) | 7 (VAC/ZC/VCC/FB/DRAIN/2×GND) |
| 所有电气参数 | **完全相同** | **完全相同** |

## 管脚说明 (SOP-7)

| 管脚 | 名称 | 功能 |
|------|------|------|
| 1 | VCC | 芯片电源，0.1~1μF 陶瓷电容到 GND |
| 2 | FB | 输出反馈控制端，接光耦发射极 |
| 4 | DRAIN | 内部 MOSFET 漏极，同时提供自供电 |
| 5, 6, 7, 8 | GND | 芯片地 / MOSFET 源极（四引脚增强散热） |

> 注意：BPA8604D 的 SOP-7 引脚与 BPA850x SOP-7 兼容（VCC=1, FB=2, DRAIN=4, GND=5~8），但控制架构完全不同。
