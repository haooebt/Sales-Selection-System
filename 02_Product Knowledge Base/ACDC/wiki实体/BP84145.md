# BP84145 — 镜像自供电 PSR Flyback 控制器 (BP84147 固定 IPK 减配版, SOP-8, 12W)

## 一、芯片架构全景

BP84145 是 BPS **第二代镜像自供电 PSR BJT Flyback** 的中功率型号。它与 [[wiki/实体/BP84147]] 共享完全相同三大创新架构（镜像电流采样 + 源极开关自供电 + HV 自启动），但**去掉了 SET 引脚**（Pin3 变 NC），IPK 固定为 740mA（而非 BP84147 的 SET 两档可调 740/880mA）。

| 维度 | BP84145 (本芯) | BP84147 (旗舰) | BP84136 (同封一代) |
|------|---------------|----------------|-----------------|
| BJT VCBO | **800V** | 800V | 750V |
| Ipk | **740mA** (固定) | 740/880mA (SET 两档) | Rcs 可调 (VREF=500mV) |
| 输出功率 | **12W** | 18W | 15.5W |
| VCC_ON | **5V** | 5V | 14.5V |
| VFB_REF | **1.01V** | 1.01V | 2V |
| CS 方式 | **镜像采样 (免)** | 镜像采样 (免) | 外置 Rcs |
| VCC 供电 | **源极自供电 (免辅助)** | 源极自供电 (免辅助) | 辅助绕组 |
| Pin3 | **NC** | **SET** | VCC |
| Pin4 | **VCC** | **VCC** | **CS** |
| 封装 | SOP-8 (4×C) | SOP-8 (4×C) | SOP-8 (4×C) |
| Pdmax | 0.97W | 0.97W | 0.86W |

> BP84145 = BP84147 − SET 引脚 − 6W 功率。最核心差异：IPK 固定为 740mA，无法像 BP84147 那样通过 SET=VCC 切换到 880mA 高功率档。

## 三、核心设计公式

### 输出恒流

$$I_O = R_{DEM} \times I_{PK} \times \frac{N_P}{N_S} \times 0.5 = 0.44 \times 0.74 \times \frac{N_P}{N_S} \times 0.5 = 0.163 \times \frac{N_P}{N_S}$$

> 由于 Ipk=740mA 固定，输出电流仅通过变压器匝比 Np/Ns 调节。

### 输出电压

$$V_{OUT\_MIN} = 1.01V \times \frac{R_{FBL} + R_{FBH}}{R_{FBL}} \times \frac{N_S}{N_{aux}} - V_D$$

### 线损补偿

$$\frac{\Delta V}{V_{OUT}} \approx \frac{12\mu A \times (R_{FBL} \parallel R_{FBH})}{1.01V} \times 100\%$$

### OVP/UVP

$$V_{OVP} = \frac{1.212V \times (R_{FBL} + R_{FBH})}{R_{FBL}} \times \frac{N_S}{N_{aux}} - V_D$$

$$V_{UVP} = \frac{0.6V \times (R_{FBL} + R_{FBH})}{R_{FBL}} \times \frac{N_S}{N_{aux}} - V_D$$

## 四、引脚功能

| Pin | BP84145 | BP84147 (参考差异) | 功能 |
|-----|---------|-------------------|------|
| 1 | **FB** | FB | 反馈电压检测 + 退磁检测 |
| 2 | **GND** | GND | 内部功率管源极 (源极开关低侧) |
| 3 | **NC** | **SET** ← 关键差异! | BP84145 无连接; BP84147 为 IPK 选择 |
| 4 | **VCC** | VCC | VCC 引脚, 接 VCC 电容到 GND, 钳位至 5V |
| 5,6,7,8 | **C** | C | 内置 BJT 集电极 (4 引脚并联) |

## 五、保护功能全景

| 保护类型 | 触发条件 | 动作 |
|----------|---------|------|
| 逐周期限流 (OCP) | IPK 达到 740mA | 立即关断 BJT |
| 输出短路 (SCP) | FB < 0.6V 持续 40ms | 关断→VCC 重启 |
| FB 引脚短路 | FB > -400mV (开通期间) 连续 4 周期 | 关断 |
| 输出二极管短路 | tLEB 内连续 7 次 IPK 触发 | 关断 |
| CS 开路 (镜像异常) | 镜像电流异常 | 关断 |
| 反馈开路 (OLP) | 反馈环路开路 | 关断 |
| 输出过压 (OVP) | FB > 1.212V 持续 3 周期 | 关断 |
| VCC 欠压 (UVLO) | VCC < 3.1V | 关断→VCC 回升至 5V 重启 |
| VCC 钳位 | VCC > 5V | 内部钳位分流 |
| 过温 (OTP) | Tj > 150°C | 关断→降温 30°C 重启 |

## 六、BP84145 vs BP84147 — 详细差异分析

| 对比维度 | BP84145 | BP84147 |
|---------|---------|---------|
| **Pin3** | NC (无连接) | **SET**: VCC→880mA / GND→740mA |
| **Ipk** | 固定 740mA | 740mA 或 880mA (可选) |
| **最大功率** | 12W | 18W |
| **外围元件** | 4 元件 (VCC 电容+FB 分压×2+变压器) | 4 元件 (含 SET 跳线选择) |
| **DS 版本** | Rev.1.0 2024/04 | Rev.1.0 2023/08 |
| **已知工程问题** | **待验证** — 是否继承 BP84147 的 3 项缺陷? | 调压误触发+温升抖动+二极管开路保护误触发 |
| **其余参数** | **100% 相同** | |

> [!WARNING] BP84145 是否继承了 BP84147 的已知缺陷？
> BP84145 的 DS 发布于 2024/04（晚于 BP84147 的 2023/08），但 DS 中未提及 BP84147 调试小结中的 3 项已知问题（调压协议误触发、温升曲线抖动、输出二极管开路保护误触发）。**推测**：BP84145 作为去除了 SET/协议功能的「纯净版」，可能已从硬件层面规避了调压协议误触发问题，但温升抖动和二极管开路保护问题是否修复需要实际测试验证。
