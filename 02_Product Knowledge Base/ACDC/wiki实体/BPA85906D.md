# BPA85906D — SOP-8 封装高压非隔离开关电源驱动芯片

## 概述

BPA85906D 是 [[wiki/实体/BPA8506D]] 的 **SOP-8 封装升级版**——同 Die（700V/6Ω/700mA）、同控制架构，但封装从 SOP-7 变更为 SOP-8（4×DRAIN 增强散热），并增加了反馈开路保护。

| 参数 | BPA8506D | **BPA85906D** |
|------|----------|-------------|
| 封装 | SOP-7 | **SOP-8** |
| DRAIN 引脚 | 1× | **4× (5,6,7,8)** |
| GND 引脚 | 4× (5,6,7,8) | 2× (1,2) |
| FB 引脚位置 | 2 | **3** |
| VCC 引脚位置 | 1 | **4** |
| θJA | 129°C/W | **145°C/W** |
| Pdmax | 0.97W | **0.86W** |
| 反馈开路保护 | ❌ | **✅ 新增** |
| 应用扩展 | — | **PC待机/通信/适配器** |
| 爬电距离 | 标准 | **>3mm** (高低压脚) |

> SOP-8 的 4×DRAIN 引脚带来更好的散热路径，但 θJA 反而从 129→145°C/W（因为 GND 引脚从 4 个减为 2 个，减少了 PCB 铜皮散热面积）。

## 关键电气参数（与 BPA8506D 相同部分）

- VCC_ON=6.4V, VCC_HYS=1.4V, VCC_CLAMP=7V, VFB_REF=1.7V
- OVP=2.9V/4cyc, OLP=1.1V/400ms, SCP=0.4V/2048cyc
- fS_MIN=1kHz, fS_MAX=45kHz, DMAX=60%, tLEB=260ns
- ILIMIT_MAX=700mA (640~760mA), ILIMIT_MIN=0.2×≈140mA
- Rds(on)=6Ω/7Ω, BVdss=700V, IDS_MAX=1630mA(DC)/3060mA(脉冲)
- TOTP=145°C, THYST=40°C, ESD=2kV
- 软启动 40%/63Ts→70%/64Ts→100%
- PWM/PFM 多模式控制

## 管脚说明 (SOP-8)

| 管脚 | 名称 | 功能 |
|------|------|------|
| 1, 2 | GND | 芯片地，内部 MOSFET 源极 |
| 3 | FB | 输出电压反馈 |
| 4 | VCC | 芯片电源，0.1μF 旁路电容到 GND |
| 5, 6, 7, 8 | DRAIN | 内部 MOSFET 漏极（四引脚并联增强散热） |

## 与 PN6654 兼容性

BPA85906D 可 Pin-to-Pin 替换 PN6654（芯朋微），需增加 R1+R2+R3+C1 四个元件在 PCB 上预留位号即可实现双向兼容。

| | BPA85906D | PN6654 |
|---|:-:|:-:|
| Rds(on) | 6Ω | **3.6Ω** |
| ILIMIT | 700mA | **1150mA** |
| VCC_ON | **6.4V** | 14V |
| OVP | **有** | 无 |

### 15V/400mA 设计要点
- FR-4 双面板 60×35mm，24 元件 BOM
- 待机功耗 <83mW@230VAC（含假负载）
- 负载调整率 3.15~3.25%
- 动态 50-100%: 157~181mV, 10-90%: 336~365mV
- IC 温升@~29°C: Δ35~40°C
- Surge±2kV/EFT±4kV/ESD±20kV 全 Pass

### 三路输出 14W 设计要点
- EE1610 变压器，FR-4 双面板 50×69mm，40 元件 BOM
- **⚠️ 交叉调整率严重**：5V满载时 12V 飘至 30V、15V 飘至 30V！
- 必须保证 12V 至少有 10mA 最小负载才能维持正常输出
- 85VAC 满载 IC 温升 **Δ90.7°C**（IC 达 119.5°C！接近 OTP）
- 降额 20% 后 IC 温升降至 Δ63°C (IC=91°C)
