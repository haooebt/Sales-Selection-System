# BP84147 — 镜像电流采样 PSR Flyback 控制器 (SOP-8)

## 一、芯片架构全景

BP84147 是 BPS 产品线中**架构最激进、创新点最密集**的 PSR Flyback 控制器。它集成了多项在 BPS 乃至行业内均属**首创**的电路技术——镜像电流采样、源极开关 VCC 自供电、高压自启动——这些创新使其能够以极简外围 BOM 实现 18W 隔离 PSR Flyback 方案。

### 与 BPS 其他 Flyback 芯片的本质差异

## 二、四大 UNIQUE 架构特征 (BPS 产品线独有)

### 1. 镜像电流采样 (Mirror Current Sensing) — 免 CS 电阻

> [核心创新] BP84147 是 **BPS 全线唯一**采用镜像电流采样技术、完全免除 CS 电阻的芯片。

**工作原理**：内置三极管 (BJT) 的发射极电流通过 Sense FET 镜像复制，产生一个比例缩小的镜像电流送入芯片内部比较器。该镜像电流精确反映主功率 BJT 的峰值电流，无需在发射极回路串联功率电阻。

**与 BPS 其他芯片的对比**：

| 对比项 | BP84147 (镜像采样) | S713x / BP86213D / BPA861x / BPA8620x (传统电阻采样) |
|--------|-------------------|------------------------------------------------------|
| CS 电阻 | **无** | 需要 1~2 颗精密电阻 (1.3Ω~2.7Ω) |
| 采样损耗 | **近似零** (镜像电流极小) | I²R 损耗 (满载可达数百 mW) |
| 系统效率 | **+0.5~1%** (省去采样电阻损耗) | 基线 |
| PCB 面积 | **更小** (少 2 个元件+走线) | 需要 Rcs 及 Kelvin 走线 |
| BOM 成本 | **更低** (省 2~3 分钱) | 基线 |
| 可靠性 | **更高** (少 2 个焊点) | 基线 |
| 局限性 | 仅限 BJT 拓扑 (电流流向为发射极→Sense FET) | 可用于 BJT 或 MOSFET, 通用性更强 |

> 这项技术是 BP84147 区分于 BPS 全线产品的最核心特征。

### 2. 源极开关 + VCC 自供电 (Source-Switch + Self-Powered VCC)

> [核心创新] BP84147 是 **BPS 全线唯一**采用源极开关自供电架构的芯片。

**工作原理**：内部 BJT 的发射极不是直接接地，而是通过内部低侧 MOSFET (源极开关) 接到 GND。当此 MOSFET 开通时，BJT 发射极经低阻抗通路到 GND，BJT 正常工作。VCC 的供电可以从内部 C 引脚 (集电极) 通过内置 HV 启动管引出，在关断期间通过芯片内部电路自举调节到 5V 钳位。

**直接收益**：
- **完全免除辅助绕组** — 传统 PSR 芯片需要辅助绕组作为 VCC 供电，BP84147 不需要
- **消除辅助绕组相关的所有 BOM 成本** — 节省辅助绕组、辅助整流二极管(Vcc整流管)、VCC 限流电阻及 VCC 电容(仍保留)
- **消除辅助绕组带来的变压器的设计约束** — 简化变压器绕组设计
- **适用于宽输出电压范围** — 不受辅助绕组与输出电压比例关系的限制

**拓扑位置示意** (简化的功率级)：
```
AC Line → Bridge Rectifier → Bulk Cap → Transformer Primary → BJT_C (Pin 5-8)
                                                                   |
                                              BJT_E --- Source-Switch --- GND (Pin 2)
                                                                   |
                                                              VCC Tap → VCC Cap → VCC (Pin 4)
```

### 3. 高压自启动 (HV Self-Start) — 免启动电阻

**工作原理**：芯片内部从 C 引脚 (集电极/漏极引脚) 集成了一条高压启动电流路径到 VCC。上电时，母线高压通过内部启动管对 VCC 电容充电。当 VCC 达到 5V 时芯片开始工作。

**启动时序**：VCC_ON=5V → 启动电容仅需充电至 5V 即可触发，远低于传统 PSR 芯片的 16V。等效启动电容可以大幅减小，启动时间短。

**ISTART ≤ 1μA** — 启动电流极低，意味着高压启动管上几乎无损耗。

| 参数 | BP84147 | S713x (传统) | 差异 |
|------|---------|-------------|------|
| VCC_ON | **5V** | 16V | **-69%** |
| VCC_OFF | **3.1V** | — | 极低欠压阈值 |
| VCC_Clamp | **5V** (内部钳位) | — | 恒压自供电 |
| ISTART | **≤1μA** | ~1mA (启动电阻) | 极低 |
| 启动电阻 | **内置** | 外置 2~4 颗贴片 | 免去 |
| 辅助绕组 | **不需要** | 需要 | **免去** |

### 4. SET 引脚两档 IPK 可调

**两档设置**：
- **SET=VCC** → IPK1 = **880mA** (高功率档, 18W)
- **SET=GND** → IPK2 = **740mA** (低功率档, 约 15W)

这是一个纯数字选择方案，不需要像传统方案那样根据 CS 电阻阻值来连续调整。SET 引脚电平直接决定内部参考电流。这种设计的优势在于：
- 不需要精密电阻 (传统方案需 1% 精度 CS 电阻)
- 逻辑电平接口，抗干扰能力强
- PCB Layout 简单 (直接跳线到 VCC 或 GND)

## 四、核心设计公式

### 输出电流 (CC 模式)

$$I_{OUT} = R_{DEM} \times I_{PK} \times \frac{N_P}{N_S} \times 0.5$$

其中 RDEM=44% (典型), 代入得：

$$I_{OUT} = 0.44 \times I_{PK} \times \frac{N_P}{N_S} \times 0.5 = 0.22 \times I_{PK} \times \frac{N_P}{N_S}$$

### 输出电压 (CV 模式)

$$V_{OUT} = V_{FB\_REF} \times \frac{R_{FBL} + R_{FBH}}{R_{FBL}} \times \frac{N_S}{N_{aux}} - V_D$$

其中 VFB_REF=1.01V。

> [!NOTE] 辅助绕组
> BP84147 采用源极开关自供电，不需要辅助绕组供电。但 PSR 采样仍需辅助绕组提供 FB 电压检测信号，因此 Naux 仍然是变压器设计的必要组成部分。

### 线压降补偿量 (Cable Compensation)

$$\frac{\Delta V_{OUT}}{V_{OUT}} \approx \frac{12\mu A \times (R_{FBL} \parallel R_{FBH})}{1.01V} \times 100\%$$

### 输出过压保护 (OVP) 电压

$$V_{OVP} = 1.212V \times \frac{R_{FBL} + R_{FBH}}{R_{FBL}} \times \frac{N_S}{N_{aux}} - V_D$$

### 输出欠压/短路保护 (UVP/SCP) 电压

$$V_{UVP} = 0.6V \times \frac{R_{FBL} + R_{FBH}}{R_{FBL}} \times \frac{N_S}{N_{aux}} - V_D$$

## 七、已知工程问题与设计红线 (来自调试小结)

> [!WARNING] 已知问题 — 调压协议误触发 (Voltage Adjustment Protocol False Trigger)
> BP84147 原设计为快充协议芯片，每周期检测 FB 零交叉斜率时间。若 FB 斜率在阈值附近波动，会误触发协议调整输出电压。
>
> **缓解措施**：
> - 保持 FB 斜率在 **~250ns** (220~280ns 窗口内)
> - RCD 钳位二极管使用 **ES2J** (快恢复管, 缩短反向恢复导致的振铃)
> - 变压器设计需 **避免磁饱和** (非饱和变压器设计)
> - FB 引脚对地并联 **22pF 电容** 以滤除 FB 振铃
>
> **最终方案**：新版本芯片将移除协议检测逻辑 (针对非快充应用场景)。

> [!WARNING] 已知问题 — 温升曲线抖动 (Thermal Curve Jitter)
> 启动时驱动能力限制在 17%，然后逐步递增至 100%。此渐进式驱动导致芯片在启动阶段出现温升曲线凹陷 (先降温再升温的异常热行为)。
>
> **修复**：新版本芯片将移除渐进式驱动功能，启动瞬间即提供 100% 驱动能力。

> [!DANGER] 已知问题 — 输出二极管开路保护误触发 + 移除导致的安全风险
> 漏感振铃 > 2μs 或空载退磁 < 4μs 会误触发输出二极管开路保护。
>
> **"修复"**：新版本芯片将**移除输出二极管开路保护功能**。
>
> **此修复的致命代价** ⚠️：
> ```
> 输出二极管开路保护被移除后 →
> 若二极管在应用中真正开路 (焊接不良/过流烧毁/机械应力断裂) →
> 系统将失去最后一道保护屏障 →
> 输出电压失控 → 输出电容爆裂 / 后端电路烧毁
> ```
>
> **工程建议**：
> - 在量产阶段必须加强输出二极管的质量管控和焊接工艺审查
> - 考虑在输出端额外并联一个独立的 TVS 钳位作为后备保护
> - 评估是否可以在外围增加简单的二极管开路检测电路
> - 新版本芯片设计决策在"消除误触发"和"保留保护"之间做出了**牺牲保护**的取舍

## 十、芯片命名与控制模式解析

### 变频控制逻辑

BP84147 采用 **QR (准谐振) 变频控制**，而非脉冲数控制或定频 PWM。其频率由变压器谐振参数和负载条件共同决定：

- **重载** → 工作在 QR 模式，谷底开通 → 开关频率最高
- **轻载** → 频率自动降低，进入 DCM 深度断续
- **空载** → 最低频率降至 **160Hz** (FMIN) → 极低待机功耗

### 退磁采样时序

PSR 架构的核心——输出电压采样必须在退磁 (Demagnetization) 期间完成。RDEM=44% 意味着退磁时间需占整个开关周期的 44% 以上才能保证正确的采样窗口。

> [!WARNING] 时序约束红线
> 设计变压器时必须保证在所有工况下 (特别是满载最高频率时) 退磁时间占比 ≥ 44%。若退磁时间不足，PSR 采样将不准确，导致输出稳压精度下降。
