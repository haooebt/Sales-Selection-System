# BPA8616P — 隔离反激脉冲数控制芯片 (DIP-7)

## 📋 芯片概述

BPA8616P 是 BPS（晶丰明源）推出的高性能隔离反激（Flyback）开关电源驱动芯片，采用 **脉冲数控制** (ON/OFF Control) 架构，固定 132kHz 开关频率，集成 700V/11Ω 高压 MOSFET。与传统的 PWM/PFM 控制器不同，BPA8616P 使用简单的跳周期脉冲数调节输出电压，具有极高的环路带宽和快速动态响应，无需外部环路补偿电路。

DIP-7 封装提供 θJA=80°C/W 的优异散热性能（SOP-7 版 BPA8616D 为 129°C/W），MOSFET 源极作为散热引脚可直接通过 PCB 铜皮散热而不影响 EMI。

## 🧠 控制架构：脉冲数控制 (ON/OFF Control)

BPA8616P 使用**脉冲数控制**技术——在每个时钟周期上升沿比较 FB 脚流出电流与阈值 IFB_DIS(115μA)：
- FB 电流 < 115μA → 开通 MOSFET
- FB 电流 ≥ 115μA → 跳过该周期

这与 PWM/PFM 的根本区别在于：
- **固定限流点**：ILIMIT 不随负载变化而变化（仅在软启动和轻载时有调整）
- **固定频率**：132kHz 始终不变
- **跳周期调节**：通过跳过脉冲个数来调节平均输出功率
- **无环路补偿**：极简反馈设计，光耦 + TL431 直接控制 FB 电流

## 🛡️ 保护功能全景

### 输入欠压保护 (Brown-in)
- 启动前通过 DRAIN 引脚检测母线电压
- VDC < 85V 时 VCC 维持在 4.9V，芯片不启动
- **免外置采样电阻**——这是对 TNY276P 的核心竞争优势之一

### 输入过压保护 (Input OVP)
- MOSFET 关断后屏蔽 1.2μs，检测漏极电压
- VDRAIN > 600V 持续 1μs → 触发保护
- 退出阈值：VDRAIN < 450V 并持续 30μs
- **TNY276P 完全不具备此功能**

### 输出过压保护 (Output OVP)
- 通过辅助绕组 + 稳压二极管 + VCC 电流检测实现
- IVCC > ISD(7.2mA) → 触发保护
- **自动重启模式** (vs TNY276P 的锁死模式)
- 等待 tAR_OFF1(1.8s) 后自动重试

### 短路保护 (SCP)
- 上电/自动重启后 FB 持续 < IFB_DIS 超过 tSC(61.4ms) → 触发
- 等待 1.8s 后自动重启

### 过载保护 (OLP)
- 正常工作中 FB 持续 < IFB_DIS 超过 tOLP(45ms) → 触发
- 等待 200ms 后自动重启

### 过温保护 (OTP)
- Tj > 145°C → 停机
- Tj < 75°C → 恢复
- 70°C 大迟滞有利于系统温度控制

## 🔌 高压启动与供电架构

双模式供电：
1. **高压自供电**：DRAIN 引脚内部高压电流源对 VCC 电容充电，无需辅助绕组。空载功耗 <150mW@230VAC
2. **辅助绕组供电**：外部辅助绕组经电阻向 VCC 供电，可关闭高压电流源，空载功耗降至 <50mW@230VAC

VCC 电容仅需 0.1~1μF 陶瓷电容，VCC 内置分流稳压钳位至 6.3V。

## 📐 设计方法论 (从 DS 中提炼)

### VOR 反射电压选择
- 推荐起始值：80~100V
- 上限约束：VDS_MAX ≤ 90% BVdss (630V) → VOR ≤ 135V
- 下限约束：VOR 过小 → DMAX 降低 → 初级电流有效值增加 → 效率下降
- **5份参考设计反算 VOR 均在 80~100V 甜区**

### 最小电感量约束 (由输入 OVP 决定)
$$
L_{P\_MIN} = \frac{V_{OR} \cdot t_{RESET} - (V_{DRAIN\_OV} - V_{OR}) \cdot t_{OFF\_Delay}}{I_{LIMIT\_MIN}}
$$
- tRESET = 2.2μs (最小去磁时间，确保 OVP 正常检测)
- ILIMIT_MIN = 140mA (0.4×ILIMIT_MAX 下限值)
- **这是 BPA8616P 独有设计约束**——大多数 Flyback 芯片无此限制

> [!NOTE] 增量广播对齐
> BPA8616P 是 BPS 首个大规模对标 PI TNY276P 的隔离 Flyback 芯片。与 BPA8604P 类似(同为脉冲数控制 132kHz + DIP-7)，但 ILIMIT=350mA vs 250mA, Rds(on)=11Ω vs 20Ω, 功率级别更高(12-15W vs 4W)。**BPA8616P 是 BPS 隔离 Flyback 产品线中的中功率主力**，填补了 BPA8604P(4W) 和 BP86213D(12-15W PSR) 之间的功率空白。

## 🔧 工程注意要点

1. **去磁时间红线**：BPA8616P 的最小电感量受输入 OVP 检测窗口约束（tRESET ≥ 2.2μs），轻载短去磁时间可能误触发 OVP
2. **非隔离反激方案**（12V/0.7A 仅 27BOM）使用 MMBT3904 + 稳压管反馈，省去光耦/TL431，但耐压仅 1kV，不适用于安全隔离场景
3. **Stack FET 超宽输入方案**（85~456VAC）实测 FET VDS 峰值达 980V@456VAC 满载，需选用耐压 ≥1200V 的级联 FET
4. **多路输出交叉调整率**是 Flyback 固有痛点——12V+18V 双路在 12V 满载/18V 空载时 18V 飘至 23.4V
5. **5V/1.5A 设计**在 85VAC 满载时 IC 温度 102.5°C/输出二极管 104.2°C，需加强散热或降额使用
6. **12V/0.7A 隔离方案**在 50°C 环温下 IC=108.6°C，距 OTP 仅 36°C——建议环境温度不超过 50°C
7. **TNY276P 替换**时可直接 Pin-to-Pin，无需修改 PCB（均为 DIP-7），但需注意 FB 脚行为差异
