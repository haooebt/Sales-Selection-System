# BP85221AL — BP85221SL 的 ASOP-7/50mA/1600V 升级版

**ASOP-7 | 1600V整流+550V/30Ω全集成 | 5V/50mA | 9元件BOM | 60°C高温验证 | Surge ±2kV**

BP85221AL = [[wiki/实体/BP85221SL]] 的 **整流桥耐压翻倍(800→1600V) + 封装升级(SSOP-6→ASOP-7) + 输出提升(30→50mA)** 版。两者 ILIMIT 完全相同(110mA)——21AL 的 50mA 是通过更优散热裕量和更高整流桥耐压释放出的。

## 📐 与 BP85221SL 的差异

| 参数 | BP85221SL | **BP85221AL** | 变化 |
|------|-----------|---------------|------|
| 封装 | SSOP-6 (4.7×3.8mm) | **ASOP-7** (6.2×3.9mm) | 更大散热 |
| 整流桥耐压 | 800V | **1600V** | ×2 |
| 输出电流 | 30mA | **50mA** | +67% |
| MOS Rds(on) | 25Ω | **30Ω** | 稍高 |
| fSW_MIN | 2.8kHz | **2.4kHz** | 略低 |
| Pdmax | 0.96W | **0.45W** | 更低! |
| θJA | 130°C/W | **未标** | — |
| Vf(反馈) | 1V@2mA | **0.6V@2mA** | 更低损耗 |
| Surge | ±700V | **±2kV** | 大幅提升! |
| 假负载建议 | 5mA(1KΩ) | 5mA(1KΩ) | 相同 |
| ESD | 2kV | 2kV | 相同 |

> ILIMIT 完全相同(110mA typ)但 Pdmax 从 0.96W 降至 0.45W——这是因为 ASOP-7 封装的热阻未标但应该比 SSOP-6 高，导致同样结温下的允许功耗更低。21AL 通过将输出电流定在 50mA（而非 21SL 的 30mA）来利用 1600V 整流桥的电压裕量补偿热限制。

## 🔧 封装与引脚 (ASOP-7)

| 脚号 | 名称 | 功能 |
|------|------|------|
| 1 | ACin | 内置整流桥阳极，接AC端 |
| 2 | BUS | 内置整流桥阴极，接BUS电容正端 |
| 3 | NC | 无连接 |
| 4 | D | 内置MOS漏极，接BUS电容正端 |
| 5 | ICG | 芯片地，内置MOS源极+续流二极管阴极 |
| 6 | GND | 输出地，内置续流二极管阳极 |
| 7 | Vo | 输出采样端，反馈二极管阳极 |

注意引脚名称与 21SL 不同：21SL 的 L→ACin / BUS→BUS / ICG→ICG / GND→GND / VO→Vo。功能完全一致。

## 🔬 与 BP85221SL 共享的架构特性

- **频率自适应控制**（非 PWM/PFM）
- **软启动**：频率随 VOUT 逐渐升高（非 ILIMIT 阶梯）
- **tON_MAX=1.8μs** + **tLEB=200ns**
- **OLP only** 保护体系（3.3V/1024cyc，覆盖过载+短路）
- **OTP 145°C** / 40°C 迟滞
- 兼容 **0510色环/CD43贴片电感**
- 假负载建议 **5mA (1KΩ)**
