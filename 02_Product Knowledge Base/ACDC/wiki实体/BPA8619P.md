# BPA8619P — BPA8618P 功率再升级版 隔离反激芯片 (DIP-7)

## 📋 芯片概述

BPA8619P 是 BPA8618PD 的**进一步功率升级版**（同属 750V 高压平台），同样采用脉冲数控制架构（132kHz, 频率调制），但内置 MOSFET 参数再次跃升：Rds(on) 从 4.5Ω 降至 **3.0Ω** (-33%), ILIMIT 从 550mA 提升至 **650mA** (+18%), IDS_MAX 从 1290mA 提升至 **1400mA**。输出功率从 BPA8618PD 的 10-24W 进一步跃升至 **12-28W** (全电压/230V)。

DS 版本演变：Rev.1.0 (2022/05) → Rev.1.1 (2024/06 模板更新) → **Rev.1.2 (2025/06 电气参数和特性曲线更新)**。

## 🔧 工程注意要点

1. **Rds(on)=3.0Ω 是 BPS 脉冲数控制(DIP-7 Flyback)系列最低内阻**，使 28W 开放式输出成为可能
2. **24V/0.8A 方案效率 86.2%@230V 为 BPA861x 系列效率最高记录**——高VOUT+低Rds(on)的最优效率点
3. **tLEB=350ns 是 BPA861x 系列最长前沿消隐**——配合 650mA ILIMIT 的必然放大，空载电感约束更宽松
4. **24V/0.8A 方案 85VAC 满载 IC 温度达 112°C**——距 OTP 仅 33°C, 在 39.6°C 恒温箱中需严格热管理 (50°C 环温下预计更高)
5. **12V/1.5A 方案 24V 输出需超快恢复 SF56**——肖特基 SB5200 在 24V 输出下耐压不足 (需 ≥200V 反向耐压)
6. **ISD 从 6.9→7.5mA (+8.7%)**——VCC 引脚灌电流 OVP 触发阈值更高，辅助绕组供电设计需重新计算稳压管串联值
7. **DS Rev.1.2 (2025/06) 是最新的电气参数更新版**——ILIMIT 范围 595-705mA 确认
8. **BPA8619P 与 BPA8618PD/BPA8618P/BPA8616P 共享完全相同控制架构**——通过持续加大 MOS Die 面积实现功率逐代升级
9. **PN8177P 对比中 BPA8619P VDS 低了 80V(540 vs 620V)**——这是 BPS 脉冲数控制+内置OVP的综合优势，工作更安全
