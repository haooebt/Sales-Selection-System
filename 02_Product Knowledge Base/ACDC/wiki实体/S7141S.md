# S7141S — 超低 BOM PSR Flyback 控制器 (内置 BJT, SOP-7, 2.5W)

## 一、芯片架构全景

S7141S 是 BPS **超低 BOM PSR Flyback** 系列的最小功率型号。它继承了 [[wiki/实体/BP84147]] 的高压自启动 + VCC 自供电 + 免 CS 电阻三大创新，并进一步通过**内置 FB 下偏电阻**将外围元件极致压缩。

| 维度 | S7141S (本芯) | S7142S (升级版) | BP84147 (旗舰) |
|------|-------------|----------------|---------------|
| BJT VCBO | **850V** | 850V | 800V |
| 峰值电流 Ipk | **180mA** (固定) | 330mA (固定) | 740/880mA (SET 两档) |
| 输出功率 | **2.5W** | 5W | 18W |
| FB 下偏电阻 | **内置** | **内置** | 外置 |
| CS 电阻 | **免** (内置固定 Ipk) | **免** (内置固定 Ipk) | **免** (镜像电流采样) |
| 启动电阻 | **免** (HV 自启动) | **免** (HV 自启动) | **免** (HV 自启动) |
| VCC 供电 | **自供电** (免辅助绕组) | 自供电 | 源极开关自供电 |
| ICABLE_max | 5.5μA | 7.2μA | 12μA |
| VFB_REF | **1.1V** | 1.1V | 1.01V |
| RFBL | **内置** | **内置** | 外置 |
| 封装 | SOP-7 | SOP-7 | SOP-8 (4×C) |
| 参考设计 | 1 份 | 3 份 | 1 份 |

### 架构创新总结 — "四免"极简方案

| # | 免除项 | 传统方案需要 | S7141S 实现方式 | 节省元件 |
|---|--------|------------|---------------|---------|
| 1 | **CS 电阻** | 1~2 颗精密电阻 | 内置固定 Ipk=180mA | ~2 颗 |
| 2 | **启动电阻** | 2~4 颗高压电阻 | C 引脚高压自启动 | ~3 颗 |
| 3 | **VCC 供电二极管** | 辅助绕组+整流管 | 自供电技术 | 绕组+1 二极管 |
| 4 | **FB 下偏电阻** | 1 颗精密电阻 | **芯片内置 RFBL** | 1 颗 |

> S7141S 的 5V/0.5A 参考设计仅 **14 个元件**，是 BPS 全库最少 BOM 的隔离 Flyback 方案。

## 三、核心设计公式

### 输出恒流设置 (CC 模式)

$$I_O = 0.25 \times I_{pk} \times \frac{N_P}{N_S}$$

其中 Ipk=180mA (固定内置), Np/Ns 为变压器匝比。输出电流仅通过变压器匝比调节。

### 输出恒压设置 (CV 模式) — 轻载

$$V_{OUT\_MIN} = \left(V_{FB} + I_{FB} \times R_{FBH}\right) \times \frac{N_S}{N_{aux}} - V_D$$

其中 VFB=1.1V, IFB=92μA, RFBH 为 FB 上拉电阻。**仅需 1 颗上拉电阻即可设定 CV!**

### 满载线损补偿后输出电压

$$V_{OUT\_MAX} = \left[ V_{FB} + (I_{FB} + I_{CABLE\_max}) \times R_{FBH} \right] \times \frac{N_S}{N_{aux}} - V_D$$

### 初级电感量计算

$$L_P = \frac{2 \times P_{O\_MAX}}{\eta \times F_{max} \times I_{pk}^2}$$

建议满载频率 60kHz，提高频率可减小变压器体积但增加开关损耗。

## 四、引脚功能

| Pin | 名称 | 功能 |
|-----|------|------|
| 1 | **VCC** | 芯片供电脚。高压自启动对 VCC 电容充电至 5.2V 开启 |
| 2 | **FB** | 反馈输入端。内置下偏电阻 + 基准电流源 (92μA)，仅需 1 颗上拉电阻 |
| 3, 4 | **NC** | 悬空脚 (Rev.1.1 起 Pin3 从 FB 变更为 NC，建议 PCB 接地或悬空) |
| 5, 6 | **C** | 内置三极管集电极 (双引脚并联增强散热) |
| 7 | **GND** | 芯片地 |

> [!WARNING] FB 引脚 PCB Layout 关键约束
> FB 引脚 (Pin2) 需远离 Pin3/4 (NC)、变压器初级动点和 RCD 钳位区域。FB 分压节点面积应尽量小，上拉电阻需靠近 FB 引脚。

## 五、保护功能全景

| 保护类型 | 触发条件 | 动作 | 恢复方式 |
|----------|---------|------|----------|
| 逐周期限流 | Ipk 达到 180mA | 立即关断 BJT | 下一周期恢复 |
| 输出短路 (SCP) | FB < 0.3V 持续 **18ms** | 关断芯片 | VCC 重启 |
| VCC 欠压 (UVLO) | VCC < 2.9V | 关断芯片 | VCC 回升至 5.2V 重启 |
| 过温 (OTP) | Tj > 150°C | 关断芯片 | Tj 降至 135°C 重启 (15°C 迟滞) |
| 输出二极管开路 | 第一周期退磁时间 < Tdem_min (3.5μs) | 停止工作并锁存 | 重新上电 |

## 七、与 S713x 系列的关键差异

| 维度 | S7141S (第四代?) | S7132S (第一代) |
|------|-----------------|----------------|
| VCC_ON | **5.2V** | 16V |
| CS 电阻 | **免** (内置固定 Ipk=180mA) | 需要 |
| 启动电阻 | **免** (HV 自启动) | 需要 |
| VCC 供电 | **自供电** | 辅助绕组+整流管 |
| FB 下偏 | **内置** | 外置 |
| ICABLE_max | 5.5μA | 60μA |
| CC 系数 | 0.25 | 0.25 |
| BOM (5V/0.5A) | **14 元件** | 估计 25+ 元件 |

> S714x 系列是 S713x 的"极简革命"——通过内置固定 Ipk、FB 下偏电阻、HV 自启动和 VCC 自供电四项技术，将隔离 Flyback BOM 压缩至传统方案的一半以下。
