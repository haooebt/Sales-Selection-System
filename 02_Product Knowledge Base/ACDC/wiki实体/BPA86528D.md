# BPA86528D — 800V/0.85Ω 亚欧姆级 ESOP-10 Flyback 旗舰

## 📋 芯片概述

BPA86528D 是 BPA865xx 系列**最高功率旗舰**，也是 **全库最低内阻**的 Flyback 芯片（Rds(on)=**0.85Ω**）。采用 ESOP-10 封装（底部散热 pad），800V MOSFET，功率 40-65W，可以覆盖笔记本电源适配器级别的大功率应用。VCC_MAX=50V 为全系列最高，拥有最多的引脚（2×GND, 2×DRAIN + 底部 pad, BR, CS, FB, VCC）。

## 📐 ESOP-10 封装特性

- 2×DRAIN 引脚 (Pin 9, 10) + 底部散热 pad
- 2×GND 引脚 (Pin 3, 4)
- 2×NC 引脚 (Pin 6, 7, 11)
- 独立 BR / CS / FB / VCC 引脚
- 面积约 9×7.5mm，底部 pad 有效改善 θJA
