# BPA8505D — 中功率高压非隔离/隔离开关电源驱动芯片

## 概述

BPA8505D 是 [[wiki/实体/BPS]] BPA850x 可调输出系列的中功率桥梁芯片，精确填补了 [[wiki/实体/BPA8504D]]（ILIMIT=280mA）和 [[wiki/实体/BPA8506D]]（ILIMIT=700mA）之间的功率空白。

三款芯片共享相同的控制架构（PWM/PFM 混合模式）、引脚排列（SOP-7）、保护机制和外围电路拓扑——仅需调整电感和分压电阻即可互换。

| 参数 | [[wiki/实体/BPA8504D]] | **BPA8505D** | [[wiki/实体/BPA8506D]] |
|------|----------|-------------|----------|
| **定位** | 灵活小功率 | **中功率桥梁** | 大电流旗舰 |
| Rds(on) | 16Ω | **8.5Ω** | 6Ω |
| ILIMIT_MAX | 280mA | **440mA** | 700mA |
| ILIMIT_MIN | 84mA | **88mA** | 210mA |
| Buck CCM | 200mA | **300mA** | 400mA |
| Buck DCM | 125mA | **200mA** | 320mA |
| IDS_MAX (DC) | 600mA | **1120mA** | 1630mA |
| IDS_MAX (脉冲) | 1120mA | **2110mA** | 3060mA |
| 最高实测功率 | 2W (Buck-Boost) | **7.2W (12V/600mA Buck)** | 12W (24V/0.5A Buck) |

> **核心定位**：BPA8505D 的 8.5Ω/440mA 参数恰好位于 8504D 和 8506D 的几何中点，是 BPA850x 系列中"功率/成本/散热"三者最均衡的选型。

### 与 BPA8504D/BPA8506D 参数对称性

BPA8505D 的电气参数大部分与 8504D/8506D 相同（VCC_ON、VFB_REF、保护阈值、频率范围、tLEB、DMAX、OTP），仅在功率相关参数上形成梯度：

| 参数 | BPA8504D | **BPA8505D** | BPA8506D |
|------|----------|-------------|----------|
| Rds(on) typ | 16Ω | **8.5Ω** | 6Ω |
| ILIMIT_MAX typ | 280mA | **440mA** | 700mA |
| ILIMIT_MIN | 0.3×280=84mA | **0.2×440=88mA** | 0.3×700=210mA |
| VCC ICH1 | 4.5mA | **9mA** | 9mA |
| VCC ICH2 | 2.5mA | **5mA** | 5mA |
| IDS_MAX DC | 600mA | **1120mA** | 1630mA |
| θJC | 39°C/W | **70°C/W** | 70°C/W |

> **ILIMIT_MIN 比率突变**：8505D 的 ILIMIT_MIN=0.2×（而非 8504D/8506D 的 0.3×），说明 BPS 在 8505D 上采用了不同的最小限流策略——更低的轻载限流有助于降低空载假负载功耗，但代价是更严格的空载电感约束。

## 管脚说明 (SOP-7)

| 管脚 | 名称 | 功能 |
|------|------|------|
| 1 | VCC | 芯片电源，需外接 0.1μF 旁路电容到 GND |
| 2 | FB | 输出电压反馈，通过分压电阻采样实现输出电压调节 |
| 4 | DRAIN | 内部 MOSFET 漏极，同时向芯片提供自供电电流 |
| 5,6,7,8 | GND | 芯片地，内部 MOSFET 源极 |

## 输出电压设置

BPA8505D 通过 FB 引脚外部分压电阻设定输出电压，VFB_REF=1.7V：

$$V_{OUT} = \frac{1.7V \times (R_{FBL} + R_{FBH})}{R_{FBL}}$$

- RFBL 建议取 ~2kΩ
- RFBH 根据目标 VOUT 计算后向上微调（补偿二极管压降）
- 参见 [[wiki/公式/输出电压设定_BPA8504D]]（同架构公式共用）

## 控制模式（PWM/PFM 多模式）

与 BPA8504D/BPA8506D 完全相同的三段式控制架构（参见 [[wiki/概念/PWM_PFM多模式控制]]）：
- **重载 PFM 模式**：ILIMIT=ILIMIT_MAX(440mA) 固定，fsw 随负载增加（→45kHz）
- **中载 PWM 模式**：fsw=22kHz 固定，ILIMIT 随负载减小
- **轻载混合模式**：ILIMIT 和 fsw 同时降低（→ILIMIT_MIN=88mA, fS_MIN=1kHz）

## 软启动

与 BPA8504D 完全相同：40%→63Ts→70%→64Ts→100% ILIMIT，共 127 个开关周期。（参见 [[wiki/概念/软启动]]）

### 关键趋势洞察

1. **VOUT↑ → 效率↑**：5V/250mA (68%) → 12V/600mA (>85%) → 24V/250mA (>80%)，与 BPA8504D/BPA8506D 规律一致
2. **VOUT↑ → 纹波↓**：24V/250mA 满载纹波仅 22.5~42.5mV，为全系列最优
3. **EE13 闭环磁路优势明显**：12V/500mA EE13 方案的负载调整率 (1.84%) 远优于同功率工字电感方案
4. **12V/600mA 为最大功率设计**：7.2W，IC 温升仅 Δ43.6°C@85VAC，距 OTP 仍有 60°C 裕量
5. **Flyback 负载调整率最优**：1.4~1.6%，优于 Buck 拓扑的同功率设计
6. **Tapped Buck 效率最高但纹波最大**：5V/1.2A 效率 78.5% 但纹波 136~183mV 且动态响应差

## Tapped Buck vs Flyback 对决（5V/1.2A）

BPA8505D 是 BPA850x 系列中**唯一有 Tapped Buck 验证数据**的芯片。2021年1月的对比测试揭示了两种大电流方案的优劣：

| | **Tapped Buck** | **Flyback** |
|---|:-:|:-:|
| 满载效率 (265V) | **78.44%** | 77.10% |
| 负载调整率 | 4.5~5.3% | **1.4~1.6%** |
| 满载纹波 | 136~183mV | **108~116mV** |
| 50%-100% 动态 | 352~360mV | **182~184mV** |
| 10%-90% 动态 | 527~548mV | **211~217mV** |
| 待机功耗 (230V) | 234mW | **248mW** |
| OCP | 2.1~2.6A | 2.0~2.3A |
| 设计难度 | **难** (变压器估算难、需短接测试) | **容易** (传统 Flyback 计算) |
| 元件数 | 多 1 个二极管 + 1 个电容 | — |

> **架构师意见**：Tapped Buck 效率稍优 (+1.3pp)，但 Flyback 在纹波（-30%）、动态响应（-50%）、负载调整率（-70%）方面全面碾压，且设计更成熟可靠。**强烈推荐 Flyback 用于大电流场景**，Tapped Buck 仅在极致效率需求且接受大纹波/差动态响应的场合考虑。

详见 [[wiki/来源/2021-01_BPA8505D_TappedBuck_vs_Flyback_5V1.2A_BPS]]
