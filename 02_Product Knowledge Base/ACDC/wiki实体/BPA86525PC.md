# BPA86525PC — 825V PFM/PWM Flyback 入门型号 (DIP-7)

## 📋 芯片概述

BPA86525PC 是晶丰明源 **BPA865xx 全新一代 Flyback 系列**的入门型号，采用 **PFM/PWM + Burst mode** 多模式控制（区别于 BPA8620/BPA861x 的脉冲数控制）。集成 **825V** 高压 MOSFET（Rds(on)=3.9Ω），CS 外置电阻设定限流，BR 多功能引脚集成 Brown-in/out + Bus OVP + Burst mode 深度调节。2026 年 1 月首发。

## ⚡ 核心电气参数

| 参数 | 值 |
|------|-----|
| BVdss | **825V** (全系列最高) |
| Rds(on) | 3.9Ω typ / 4.8Ω max |
| VCS_LIMIT | 0.97V (0.88~1.2V) |
| I_D / I_DM | 3A / 8A |
| fsw | 100kHz typ (90~110), 16kHz 抖频 |
| fsw_min | 26kHz |
| DMAX | 78% (70~85) |
| tLEB | 400ns |
| TILD | 100ns |

## 🔌 VCC 供电系统

| 参数 | 值 |
|------|-----|
| VCC_ON | 15V (13~16.2) |
| VCC_OFF | 8V |
| VCC_HYS | 7V |
| VCC_OVP | 38.5V |
| IS1 (待机) | 1.15mA |
| IS2 (工作) | 1.95mA |

## 🛡️ 保护功能

| 保护 | 机制 | 参数 |
|------|------|------|
| Brown-in | BR pin > 0.9V | VCC=15V 启动 |
| Brown-out | BR pin < 0.8V 持续 75ms | 关断 MOSFET |
| Bus OVP | BR pin > 4V | 关断→自动重启 |
| 输出 OVP | VCC > 38.5V | 关断→自动重启 |
| SCP/OLP | FB > 5.2V 持续 75ms | 自动重启 |
| 逐周期限流 | CS pin, VCS_LIMIT=0.97V | 外置 Rcs 设定 |
| OTP | 150°C | 40°C 迟滞 |
