# 03_Solutions and Applications 解决方案与行业应用

这里按终端应用场景管理解决方案包。

推荐分类：

- Motor Control: 风机、水泵、电动工具、压缩机、机器人关节、电动车控制器
- BMS: 储能、电池包、保护板
- Industrial Control: 工控板、I/O 模块、工业通讯
- Power Supply: 电源、充电器、适配器
- Home Appliance: 家电控制，优先入口 `Home Appliance/Home Appliance Solution Map.md`

每个场景建议建立方案卡，回答：

- 典型系统是什么？
- 客户常见需求是什么？
- 关键器件和资源是什么？
- 我司推荐产品组合是什么？
- 需要问客户什么问题？
- 有没有已验证案例？
