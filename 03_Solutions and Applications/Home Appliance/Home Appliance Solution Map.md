# Home Appliance Solution Map

本文件用于快速定位大家电/家居应用中的我司产品组合。它服务于两类任务：

- 客户给终端应用场景时，快速推导可推荐方案。
- 客户给竞品规格书时，在芯片级替代之外补充应用级风险判断。

资料来源：

- `大家电产品介绍-Q2Y26.pptx`
- `晶丰明源roadmap-26Q1 .pptx`
- `凌鸥创芯产品介绍(大家电应用)-Mar V2.3.pdf`

## 一句话结论

家电方案资料覆盖三条主线：

- BPA 工业级家电辅助电源：Buck/Buck-Boost、隔离 SSR、非隔离反激、大功率 ACDC。
- 电机控制：LKS32 MCU + Gate Driver/IPM + 控制算法，覆盖空调、洗衣机、干衣机、冰箱、油烟机、洗碗机、强排风机和水泵。
- 白电 IPM：面向空调内风机、空调外机、冰箱压缩机、高压风机等功率级应用，重点推广自供电和 SiC 方案。

## 竞品替代时的使用方法

如果竞品是 ACDC：

- 先判断 Buck/Buck-Boost、隔离 SSR、非隔离反激、微波炉电源还是大功率 ACDC。
- 再按功率、电压、电流、封装、是否 P2P 线索进入 BPA 快速表。
- 对 P2P 替代必须继续核对 pinout、保护模式、VCC/FB/Drain BV、待机功耗和 EMI。

如果竞品是 MCU：

- 先按应用场景判断是否需要 PFC、多电机、OOB/称重、ClassB、无感 FOC、主变一体。
- 再用 MCU 系列定位表缩小到 MC45x、MC07x、MC08x 或 MC03x。

如果竞品是 IPM/Gate Driver：

- 先按耐压、电流、封装、自供电/自举、OCP/FO/SD、是否 SiC 判断。
- 白电场景优先参考上面的 IPM 选型线索。
