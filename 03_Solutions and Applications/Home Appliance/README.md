## 使用建议

当客户给的是“应用场景”而不是明确芯片型号时，优先读 [[Home Appliance Solution Map]]。

当客户给的是竞品规格书时：

1. 先判断竞品类别：ACDC、MCU、IPM、Gate Driver。
2. 再看该竞品是否属于家电场景。
3. 若属于家电场景，同步参考 [[Home Appliance Solution Map]] 中对应应用的推荐组合。
4. 输出报告时同时给出“芯片级替代”和“方案级推荐”。
