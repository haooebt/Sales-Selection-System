# 00_Workbench 工作台

这里放临时资料和正在处理的需求。

适合放：

- 刚收到、还没分类的产品手册
- 客户临时发来的规格书
- 待整理的微信/邮件需求
- 快速判断记录

不适合长期保存：

- 已完成的客户案件
- 已整理好的产品资料
- 已确认的竞品替代表

建议每周清理一次：

1. 产品资料移入 `02_Product Knowledge Base`。
2. 方案资料移入 `03_Solutions and Applications`。
3. 竞品资料移入 `04_Competitor and Replacement`。
4. 客户资料移入 `01_Customer Cases`。
