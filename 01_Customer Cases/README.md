# 01_Customer Cases 客户选型案件

每个客户需求都建议建立一个案件文件夹，哪怕只是一次初步咨询。

推荐结构：

```text
客户名_项目名_YYYY-MM/
├─ 00_Case Card.md
├─ 01_Customer Raw Materials/
├─ 02_Requirement Breakdown.md
├─ 03_Selection Process.md
├─ 04_Recommendation.md
├─ 05_Customer Output/
└─ 99_Case Review.md
```

案件分类：

- 竞品替代：客户有在用型号或规格书。
- 参数选型：客户有明确参数需求。
- 项目场景建议：客户只有终端项目或应用方向。

每个案件必须记录：

- 客户输入
- 关键需求
- 推荐型号
- 推荐理由
- 风险点
- 待确认问题
- 下一步动作
